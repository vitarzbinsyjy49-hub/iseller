# Папка приёма фотографий товаров (intake)

Сюда кладите **реальные фотографии товаров** для загрузки в каталог AI Seller.
Загрузка идёт через уже готовый **Import Center** по схеме «предпросмотр
(dry-run) → подтверждение» — ничего необратимого «в один клик» не происходит.

## 1. Как назвать файлы

Имя файла (без расширения) = **SKU товара** (как в админке / прайсе).
Суффикс задаёт порядок в галерее; первое фото становится главным:

| Файл                        | Что это                     |
|-----------------------------|-----------------------------|
| `IPH15PRO128BLACK.jpg`      | главное фото                |
| `IPH15PRO128BLACK_main.jpg` | главное фото (альтернатива)  |
| `IPH15PRO128BLACK-1.jpg`    | второе фото галереи         |
| `IPH15PRO128BLACK-2.jpg`    | третье фото галереи         |

- Регистр SKU не важен. Форматы: `jpg / jpeg / png / webp / gif`, до 8 МБ на файл.
- Полные правила именования: [`docs/IMAGE_NAMING_GUIDE.md`](../docs/IMAGE_NAMING_GUIDE.md).

## 2. Как загрузить (безопасно, с предпросмотром)

1. Заархивируйте содержимое этой папки в ZIP (можно вместе с прайсом —
   получится «Import Pack»).
2. Админка → **Импорт** → перетащите ZIP → **Предпросмотр (dry-run)**.
   БД не меняется: видно, каким товарам сматчились фото, что осталось без
   совпадения (`unmatched`), какие ошибки.
3. Исправьте имена по отчёту при необходимости и повторите предпросмотр.
4. Нажмите **Импортировать** — только тогда фото сохраняются и попадают в БД.

Только фото, без прайса: Админка → **Медиа** → «ZIP с фото товаров»
(эндпоинт `POST /api/admin/uploads/products/images-zip`) — тоже сначала
показывает отчёт совпадений.

## 3. Manifest (необязательно)

Для пакетного импорта можно вложить в ZIP `manifest.json` с параметрами —
см. [`manifest.example.json`](manifest.example.json). Сопоставление фото с
товаром идёт по имени файла (= SKU), отдельный mapping-файл не нужен.

## 4. Готовые проверенные фото (Apple + Dyson)

В рабочей папке проекта уже лежат заранее подготовленные и проверенные фото:
`ISELLER/photo-audit/out/AI_SELLER_PHOTOS_REUSE_VERIFIED.zip`
(файлы названы по SKU). **Важно:** эти SKU относятся к каталогу
**BSA / rocketniks (Apple + Dyson)**, а НЕ к текущему демо-сиду и не к
прод-товарам (у них `sku = null`). Чтобы фото сматчились, сначала загрузите
этот товарный каталог (Импорт прайса), а затем ZIP с фото. Иначе фото уйдут в
`unmatched` — это ожидаемо, не ошибка загрузчика.

## 5. Откат загрузки фото

Отдельного «отката импорта фото» нет. Удалить/заменить фото товара:
Админка → Товары → Изменить → Фотографии (удаление с подтверждением, выбор
главной). Перед крупным импортом на проде делается `pg_dump` (см.
`update-server.sh`) — это общий бэкап БД, к которому можно откатиться.
