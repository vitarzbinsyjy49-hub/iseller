# Telegram-посты в админке

Раздел **Посты** хранит черновики, позволяет редактировать и одобрять их, а затем
публикует в Telegram только после отдельного подтверждения администратора.

## Настройка

1. Добавьте бота администратором канала с правом публикации сообщений.
2. В `.env` заполните:

   ```env
   TELEGRAM_BOT_TOKEN=123456:token
   TELEGRAM_CHANNEL_ID=@channel_username
   ```

   Для приватного канала используйте числовой идентификатор вида `-100...`.
3. Пересоберите backend и admin.

## Гарантия ручного подтверждения

- Генератор имеет право создавать только статус `draft`.
- Одобрение фиксирует номер версии текста.
- Любое редактирование снимает одобрение.
- `/publish` принимает только `approved` с совпадающей версией и
  `{"confirm": true}`.
- Ошибка Telegram не меняет статус на `published`.

## API генератора

Внешний сборщик новостей должен создавать каждый вариант через
`POST /api/admin/posts` с администраторским JWT. Поля: `title`, `body`,
`image_url`, `kind` (`news`, `guide`, `opinion`) и массив `sources`.
Endpoint намеренно не принимает статус — новый материал всегда становится
черновиком.
