# Импорт товаров (Import Center, v4)

Массовая загрузка/обновление каталога из прайса. Работает в админке:
**Админка → Импорт**, или напрямую через API.

## Форматы

| Формат | Расширение | Примечание |
|--------|-----------|------------|
| CSV    | `.csv`    | разделитель `,` или `;` (определяется автоматически), кодировка UTF-8 |
| JSON   | `.json`   | массив объектов или `{"items": [...]}` |
| XLSX   | `.xlsx`   | первый лист, первая строка — заголовки |

Шаблон: [templates/products_template.csv](../templates/products_template.csv)
(его же можно скачать кнопкой прямо в админке).

## Два шага: preview → confirm

1. **Проверить (preview)** — файл разбирается и валидируется, в базу ничего
   не пишется. Вы видите: сколько строк создаётся/обновляется/пропущено,
   ошибки и предупреждения по каждой строке.
2. **Импортировать (confirm)** — тот же файл применяется к базе.

API (JWT админа, multipart-файл в поле `file`):

```
POST /api/admin/import/products/preview
POST /api/admin/import/products/confirm
```

## Правила

- **`sku` обязателен** — это ключ матчинга. SKU уже существует → товар
  обновляется; новый SKU → товар создаётся. Старые товары никогда не удаляются.
- Для **новых** товаров обязательны `title` и корректная `price`.
- Цена принимает форматы `89990`, `89 990,50`, `89990.50 ₽`.
- Пустой `stock` → 0 (и `in_stock` выставляется автоматически: stock > 0).
- Пустой `is_active` → `true`.
- Булевы поля понимают: `1/0`, `true/false`, `да/нет`, `+/-`.
- `condition`: `new` / `used` / `refurbished` (иное → warning и `new`).
- `specs` — JSON-объект (`{"экран":"6.1\""}`), `tags` — JSON-массив или строка
  через запятую (`хит,титан`).
- `image_1..image_3` — URL картинок; `image_1` становится главной.
  Обычно проще загрузить фото ZIP-архивом — см. [IMAGE_NAMING_GUIDE.md](IMAGE_NAMING_GUIDE.md).
- Дубль SKU внутри одного файла → вторая строка пропускается с ошибкой.
- Лимиты: 2000 строк, файл до 20 МБ.

## Поддерживаемые колонки

`sku, title, brand, category, subcategory, price, old_price, stock, condition,
warranty_months, color, memory, storage, screen_size, cpu, ram, description,
specs, tags, image_1, image_2, image_3, is_hot, is_available_today, is_active`

Неизвестные колонки игнорируются — можно скармливать «живой» прайс.

## Типовой сценарий «загрузить 100 товаров с фото за 10 минут»

1. Заполните CSV/XLSX по шаблону (sku, title, price — минимум).
2. Админка → Импорт → выберите файл → **Проверить** → посмотрите отчёт → **Импортировать**.
3. Соберите фото в ZIP, назвав файлы по SKU (`IPH15PRO128BLACK.jpg`, `-1.jpg`, `-2.jpg`).
4. Админка → Медиа → загрузите ZIP → проверьте отчёт матчинга.
5. Откройте Mini App — товары с фото уже на витрине.


## v5.2: пакетный импорт и новая семантика
- Несколько файлов + ZIP фото за один раз — см. **BATCH_IMPORT_GUIDE.md**.
- ВАЖНО: для существующего SKU пустое поле теперь означает «не менять» (пустой stock больше не обнуляет остаток, пустой is_active не включает товар). Явные stock=0 / is_active=false применяются. Для новых товаров дефолты прежние.
- Появились режимы: create_or_update (default) / update_only / create_only.
