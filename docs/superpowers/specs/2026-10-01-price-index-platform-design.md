# «Индекс Айселлера» — большая надстройка: карта масштаба

_Статус: **утверждено владельцем 2026-10-01** (порядок S1→S6, схема сбора
«кнопка → черновик → подтверждение в админке»). Дата: 2026-10-01._
_Это НЕ спека одной фичи, а карта подпроектов. У каждого подпроекта будет
своя спека → план → реализация._

## Зачем

Магазин продаёт технику дешевле рынка (цена = BSA − 500 ₽), но об этом никто не
знает. Цель — много подписчиков в Telegram и заявки менеджеру. Надстройка
превращает «у нас дешевле» из лозунга в **проверяемые данные**, вокруг которых
строятся сайт, контент, алерты и AI-сравнение.

## Решения, принятые в разговоре 2026-10-01

### Headless-браузер на прод-сервере (тот же день, Playwright 1.55, контейнер 600–750 МБ)

| Магазин | Результат с сервера | Где собирать |
|---|---|---|
| МТС | ✅ цены есть (114 990 / 119 990 …) | **сервер** |
| Store77 | ✅ цены есть (98 880 …) | **сервер** |
| BigGeek | ✅ (хватает и curl) | **сервер** |
| re:Store | ✅ curl | **сервер** |
| DNS | ❌ 401/403 — режет IP дата-центра | **Mac mini** |
| Ситилинк | ❌ 429 (с 600 МБ — «Page crashed», с 750 МБ — 429) | **Mac mini** |
| Яндекс Маркет | ❌ «Вы не робот?» | **Mac mini** |

Режимы `chromium` (полный) и headless shell дали одинаковый результат — на
сервере берём shell (меньше памяти). Свободно на сервере ~950 МБ RAM, поэтому
браузерный сбор — ночью, последовательно, в контейнере с лимитом памяти.
Тестовый образ и файлы удалены, health магазина `ok`.

### Playwright с ПК владельца (этап 1, 2026-10-01, Playwright 1.63)

IP при проверке — `77.37.219.232`, по RIPE `NCN-BBCUST` («NKS broadband
customers»), то есть домашний провайдер, а не дата-центр. Владелец в это время
мог быть в кофейне — если это не домашняя сеть, повторить таблицу из дома.
Запрос — «iPhone 17 Pro», страница поиска.

| Источник | A: headless chromium | B: `channel="chrome"`, свой профиль, окно | B + без флагов автоматизации |
|---|---|---|---|
| DNS | ❌ 401 → «Доступ запрещён» с IP | ❌ то же | ✅ 48 цен |
| Ситилинк | ✅ 20 цен (первый ответ 429, потом страница дорисовалась) | ✅ | ✅ |
| Яндекс Маркет | ❌ 403 | ✅ 12 цен | ✅ |
| Яндекс Товары | ❌ «Вы не робот?» | ❌ капча | ❌ капча; ✅ после прогрева профиля |

- **DNS ловит автоматизацию, а не IP:** с того же IP обычный браузер открывает
  поиск (382 товара). Проходит только с
  `ignore_default_args=["--enable-automation"]` и
  `--disable-blink-features=AutomationControlled`.
- **Яндекс Товары** пускают после прогрева в том же профиле: `ya.ru` →
  `yandex.ru/products` → поиск. Поиск сам уводит на
  `yandex.ru/search?text=…&products_mode=1` — там предложения магазинов с ценами
  (Store77, М.Видео, DNS, OZON и мелкие). «Рыночной стоимости от–до» на этой
  странице нет — искать её на карточке товара при реализации; не нашлась —
  источник даёт только предложения.
- **Вывод для `collectors/`:** один режим на все 8 источников — установленный
  Google Chrome (`channel="chrome"`), постоянный профиль в `collectors/`, окно
  (не headless), без флагов автоматизации, перед Яндексом — прогрев. Отдельный
  headless-chromium не нужен.
- **CDP к открытому Chrome владельца не понадобился.** Если всё же придётся:
  Chrome 136+ не открывает порт отладки на профиле по умолчанию, нужен отдельный
  `--user-data-dir` — то есть та же история, что и постоянный профиль Playwright.
- Капчи не решаем и не обходим сервисами. Появилась — источник в этом прогоне
  выпадает, в партии помечается.
- Сохранённые страницы этого теста (HTML и скриншоты) — заготовка фикстур для
  тестов сопоставителя на этапе 4.

### S1. Радар цен (данные) — первым

**Утверждённая схема (D8):** сбор по кнопке, публикация только после
подтверждения человеком. Автоматики по расписанию на старте нет.

```
Ярлык «Обновить цены» на ПК владельца (или «обнови цены» в сессии Claude)
   → collectors/ обходит 8 источников с домашнего IP (~3–5 мин):
     МТС, Ситилинк, DNS, BigGeek, Store77, re:Store, Яндекс Маркет, Яндекс Товары
   → POST /api/prices/ingest → партия в статусе DRAFT (на сайте не видна)
   → уведомление владельцу в Telegram: «собрано N, требуют проверки M»
   → админка «Радар цен»: 🟢 уверенно / 🟡 проверить / 🔴 не сопоставлено
   → «Опубликовать» → партия PUBLISHED, индекс обновлён с датой
```

- 🟢 — однозначное сопоставление и изменение к прошлой публикации ≤15%;
  галочка стоит заранее. 🟡 — новое объявление или изменение >15%: смотреть
  по ссылке. 🔴 — не сопоставилось, в индекс не идёт.
- Сбор по **странице семейства** (поиск «iPhone 17 Pro» даёт все цвета/память),
  а не по каждой позиции: ~6 семейств × 7 магазинов ≈ 42 страницы.
- Первый пункт реализации — проверка, пускают ли DNS/Ситилинк/ЯМаркет
  Playwright с ПК владельца (OpenCLI с настоящим Chrome — пускали). Запасной
  вариант — Playwright с `channel="chrome"` и постоянным профилем, не headless.
- Позже (не в S1): тот же скрипт на Mac mini по расписанию, 🟢 публикуются
  сами, человеку — только 🟡/🔴.
- Модели: источник (магазин), партия сбора (draft/published, кто и когда
  опубликовал), наблюдение (сырая строка: название, цена, ссылка, время),
  сопоставление наблюдение→наш `family_key`/вариант.
- `POST /api/prices/ingest` с токеном сборщика; идемпотентность по
  (источник, ссылка, партия).
- Сопоставитель: нормализация названий (память, цвет RU/EN, SIM-тип, регион,
  «без RuStore» = зарубежная версия, ASIS/витрина). Неоднозначное — в очередь
  ручного подтверждения в админке («Радар цен»), а не в индекс.
- Сборщики: `collectors/` — самостоятельный пакет (Python + Playwright), конфиг
  «магазин → URL поиска/категории → селекторы», режимы `--dry-run` (таблица в
  файл) и `--push`.
- Устаревание: цена старше 3 дней не показывается; магазин молчит 3 дня →
  алерт владельцу (механика уведомлений уже есть).
- **Готово, когда:** 20 ходовых позиций × 6 магазинов собираются раз в день,
  таблица сопоставлений проверена глазами.

### S2. Сайт-мост (MVP)

**Решение владельца 2026-10-01 (D9): на сайте ничего не продаётся.** Сайт —
полезный бесплатный медиа-лендинг, главное действие — переход в Telegram.
Никаких корзин, «купить» и форм с телефоном; данные клиента собираются только
в боте (кнопка Telegram «Поделиться контактом» при заявке). На сайте —
только Яндекс Метрика (уведомление о cookies + политика конфиденциальности).
Внизу: «Информационный сайт, не интернет-магазин и не оферта; цены других
магазинов — с их сайтов на указанную дату».

Полезные функции (каждая заканчивается продолжением в боте с контекстом
через deep link `ad_site-<функция>[_product_<id>]`):
1. **Индекс цен + «брать или ждать»** → «Сообщить, когда подешевеет» (бот, S3).
2. **«Где дешевле?»** — поле поиска → таблица цен по магазинам из индекса
   (детерминированный поиск, без LLM; LLM — позже, S4) → «Получить цену
   Айселлера» (бот открывает товар).
3. **«Проверь, оригинал ли»** — пошаговая проверка (серийник, IMEI, коробка) →
   «Проверим за тебя» (бот).
4. **Статьи** — сначала на сайте (оригинал), потом адаптация на Дзен со
   ссылкой (иначе Яндекс склеит дубли не в нашу пользу).
5. Позже: мини-игра «Угадай цену» → приветственные баллы в боте (система
   лояльности уже есть).

Ниже — исходные пункты S2; про «купить», форму телефона и витрину они
отменены решением D9.
- Свой домен (решение владельца), Caddy.
- Серверный рендер страниц (решение по стеку — в спеке S2; кандидат по
  умолчанию — Jinja-шаблоны в FastAPI, без нового стека).
- Страницы: главная, разделы (из `catalog_nav`), страницы модели с индексом
  цен и графиком, условия (гарантия, самовывоз Горбушкин двор, доставка),
  статья «как проверить оригинальность».
- Для поиска и нейросетей: `sitemap.xml`, `robots.txt` (разрешить YandexBot,
  GPTBot, OAI-SearchBot, PerplexityBot), `llms.txt`, schema.org
  `Product/Offer/ItemList`.
- CTA: «Получить эту цену в Telegram» → `t.me/<bot>?start=ad_site-<страница>`
  (+ `_product_<id>` где есть товар).
- Telegram в РФ с весны 2026 без VPN почти не работает (iseller-ads
  `docs/07-growth-plan.md` §1), но **владелец решил: Telegram остаётся домом,
  запасной дом не строим** (iseller-ads `docs/decisions.md`, 2026-10-01).
  Открытый вопрос для спеки S2: нужна ли на сайте форма телефона с согласием
  на ПДн (152-ФЗ) → заявка без telegram_id — как страховка для тех, у кого
  Telegram не открылся. Это новый путь создания заявки; решает владелец.

**Ресурсы сервера (замер 2026-10-01):** диск 58 ГБ, занято 19, свободно 37
(из них ~3,9 ГБ — журналы systemd, ~5,9 ГБ — кэш сборки Docker, оба
чистятся). RAM 1,9 ГБ, доступно ~950 МБ, swap 2 ГБ; магазин целиком ~180 МБ,
самый тяжёлый процесс — `warp-svc` ~310 МБ. Нагрузка 0,2–0,5 на 2 ядра.
Сайт на том же бэкенде + кэш в Caddy докупки сервера не требует.
- **Готово, когда:** сайт в Яндекс Вебмастере, переходы с сайта видны в
  отчёте `ad_touch`.

### S3. Алерты «сообщить, когда подешевеет» + лист ожидания
- Подписка на модель из сайта и из Mini App → только через чат бота (право
  писать человеку). Переиспользовать `favorite_watch` / `notifications`.
- Ежедневный дифф наших цен и индекса → уведомление.
- Лист ожидания релизов (iPhone 18, PS6…) — пики подписок вокруг презентаций.

### S4. AI-сравнение «где дешевле оригинал»
- На сайте и в боте: запрос → наши кандидаты (существующий retrieval) +
  сопоставленные предложения конкурентов → таблица «магазин — цена — дата —
  ссылка».
- Инвариант из `docs/context/ai.md` сохраняется: **цены только из БД**, модель
  ничего не утверждает о деньгах сама.
- Внизу всегда действие: «Взять у нас» или «Нашли дешевле — перебьём».

### S5. Контент-движок
- Еженедельный отчёт индекса: «что подешевело/подорожало» → черновик поста в
  «Посты канала» (модерация уже есть), черновик статьи для Дзен/VC
  (markdown), данные для шортса.
- Позже: автосборка data-видео (шаблон + озвучка).

### S6. Отчёт по воронке
- По каждой метке: визиты сайта (Метрика) → старт бота (`ad_touch`) → вход в
  Mini App → заявка → покупка. Расширение раздела «Аналитика» админки.

### S7. GEO-мониторинг (вне кода)
- Раз в месяц 15–20 вопросов «где купить дешевле…» в Алису AI и Perplexity,
  фиксировать, упоминается ли Айселлер и какие страницы цитируются. Ведётся в
  проекте «Айселлер Реклама».

## Передача на Mac mini

Когда S1 работает локально:
1. В репозитории лежит `collectors/MACMINI_SETUP.md` — готовый запрос для Claude
   Code на Mac mini: установить Python + Playwright, склонировать только
   `collectors/`, положить `.env` (`INGEST_URL`, `INGEST_TOKEN`), настроить
   `launchd` на ежедневный запуск, проверить первый `--dry-run` и `--push`.
2. Сборщик шлёт heartbeat; тишина 3 дня → алерт владельцу.
3. Тот же Mac mini потом примет Ollama (ROADMAP, ШАГ 3) — сборщику это не мешает.

## Риски

| Риск | Что делаем |
|---|---|
| Сайт меняет вёрстку → парсер молча врёт | Валидация: цена в разумном диапазоне от вчерашней, доля сопоставленных строк; аномалия → не публикуем, алерт |
| Антибот усилится | Один запрос в день на страницу, домашний IP, настоящий профиль Chrome; при блоке — магазин выпадает, индекс помечает дату |
