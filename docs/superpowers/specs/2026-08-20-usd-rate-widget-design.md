# Курс доллара на главной + шторка «Курс и цены»

Дата: 2026-08-20

## Контекст

Идея: показать актуальный курс USD в свободном месте справа от тумблера
«Категории / Бренды» на главной (`Home.tsx:451`, тёмный hero-блок). Цель —
не декор, а объяснение колебаний цен: часть техники (iPhone, MacBook,
PlayStation) везётся из Кореи и Гонконга за доллары, и курс — легальная
причина, почему цена на складе иногда двигается.

Источник курса — официальный курс ЦБ РФ через публичное бесплатное
зеркало `cbr-xml-daily.ru/daily_json.js` (JSON, без ключа, без лимитов).
Своей внутренней ставки закупки в проекте нет и заводить её ради этой
фичи не стоит (см. `docs/context/bsa-price-sync.md` — там о конкурентных
ценах, не о курсе).

Утверждён визуально (см. обсуждение в чате): чип в стиле тумблера
(вариант B), тап открывает bottom-sheet с графиком и пояснениями.

## Backend: хранение курса

Новая таблица `fx_rate_history` (создаётся автоматически через
`Base.metadata.create_all`, миграция не нужна — по аналогии с
`RevokedRefreshToken`, см. `backend/app/models/revoked_token.py`):

```python
class FxRateHistory(Base):
    __tablename__ = "fx_rate_history"
    id: Mapped[int] = mapped_column(primary_key=True)
    date: Mapped[date] = mapped_column(Date, unique=True, index=True)
    value: Mapped[float]  # ₽ за $1
    fetched_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())
```

Одна строка на календарный день — это одновременно и история для
графика, и «кэш» текущего значения: отдельного in-memory TTL-кэша не
заводим, читаем последнюю строку напрямую. Проще и переживает рестарт
процесса, в отличие от in-memory варианта.

**Наполнение — в фоновом тике бота**, по образцу `_warm_gateway`
(`backend/app/scripts/bot_polling.py:122`, вызывается из `_tick`). Новая
функция `_sync_fx_rate(state, now)`:

- на каждом тике (≤30с) дешёвый запрос `SELECT 1 FROM fx_rate_history
  WHERE date = today() LIMIT 1`;
- если строка уже есть — выходим, ничего не делаем;
- если нет — `GET cbr-xml-daily.ru/daily_json.js`, достаём
  `Valute.USD.Value`, вставляем `(date=today, value)`;
- ошибка сети/парсинга — лог + возврат, БЕЗ падения тика (тот же
  fail-soft принцип, что у `check_rate_limit`, `_init_redis` и
  `_warm_gateway`). Следующий тик (через ≤30с) попробует снова — отдельный
  таймер-гейт не нужен, DB сама решает, нужна ли попытка.

Не отдельный планировщик — обоснование то же, что у `_tick` в целом
(комментарий `backend/app/scripts/bot_polling.py:151`): процесс уже
крутится постоянно.

## Backend: отдача данных

**Текущее значение** — в `GET /api/config/public` (`app/api/config.py`)
добавляется поле `usd_rate: {value: float, delta: float} | null`.
`delta` = value последней строки минус value предпоследней (0, если
строка всего одна). `null`, если строк ещё нет вообще (холодный старт —
первый тик ещё не успел отработать) — фронт в этом случае чип не
рисует, а не показывает 0 или битый вид. Тот же принцип, что у
`ai_vendor`: «недоступно = молчание, не дефолт» (см. `docs/context/ai.md`).

**История для графика** — новый эндпоинт `GET /api/fx/history?days=30`
(публичный, без авторизации — это не персональные данные, обычный
рыночный курс). Отдаёт до `days` последних строк по возрастанию даты:
`[{date, value}, ...]`. Лениво — дергается фронтом только при открытии
шторки, не на каждой загрузке главной.

## Frontend: чип на главной

`Home.tsx:451` — обёртка тумблера меняется с `flex items-center` на
`flex items-center justify-between`, чип встаёт вторым элементом.
Рендерится **независимо от `hasBrandAxis`**: если тумблера нет (бренды не
пришли), строка всё равно рисуется — просто с одним чипом без тумблера,
а не с пустым пространством. Чип не рендерится вовсе, если
`usd_rate === null`.

Вид (см. одобренный мокап, вариант B): пилюля в стиле
`SegmentedToggle` (`bg-white/[0.13]`, `ring-1 ring-inset ring-white/15`),
`$91,2 ▲0,3` — знак и цвет дельты (`text-green`/`text-danger`) зависят от
знака. Формат — `Intl.NumberFormat("ru-RU", {minimumFractionDigits: 1,
maximumFractionDigits: 1})`.

## Frontend: шторка «Курс и цены»

Новый компонент `components/FxRateSheet.tsx`, переиспользует `SheetShell`
(`components/ScenarioSheet.tsx:29`) — по образцу `AiRoadmapSheet.tsx`,
второй шелл не заводим (см. инвариант в `docs/context/*` про `SheetShell`).

Открывается тапом по чипу, текущее значение/дельта передаются пропом (уже
есть из `/config/public`, повторно не грузим). При открытии — ленивый
`GET /api/fx/history?days=30`, пока грузится — скелетон графика.

Четыре блока сверху вниз (порядок как в одобренном мокапе):

1. **Курс крупно + дельта + источник** («Курс ЦБ РФ · обновлено сегодня
   в HH:MM» — время из `fetched_at` последней строки).
2. **Объяснение** — статичный копирайт (см. мокап), не из БД/админки:
   контент фиксированный, редактировать через код, отдельного поля в
   админке не заводим (YAGNI — не просили).
3. **График за 30 дней** — SVG-полилиния, точки нормализуются к
   viewBox чистой функцией `toSparklinePoints(values, width, height)` в
   новом `lib/sparkline.ts` (тестируется без DOM, по образцу
   `scrollPositionAt`/`easeOutQuint` в `lib/motion.ts`). Если строк
   меньше 30 (только что запустили фичу) — рисуем что есть, подпись
   «Копим историю с запуска — график будет за месяц» вместо тишины.
4. **Совет** + **FAQ** — статичный копирайт, как и объяснение.

## Нефункциональные решения (YAGNI)

- Только USD, только курс ЦБ. Другие валюты/источники — не просили.
- Текст блоков объяснения/совета/FAQ — захардкожен на фронте, не через
  админку/БД. Расширять до редактируемого контента — отдельная задача,
  если понадобится.
- Не откатываем историю назад через API ЦБ за прошлые месяцы — копим
  свою с нуля (осознанное решение, см. обсуждение).

## Тестовый план

- Backend: `_sync_fx_rate` не пишет вторую строку за тот же день
  (идемпотентность); сетевая ошибка не роняет `_tick`; `GET
  /config/public` отдаёt `usd_rate: null` при пустой таблице и
  `{value, delta}` при заполненной (delta=0 на единственной строке);
  `GET /api/fx/history?days=N` отдаёт не больше N строк по возрастанию
  даты.
- Frontend: `toSparklinePoints` — граничные случаи (1 точка, все значения
  равны — не делить на ноль); чип не рендерится при `usd_rate: null`;
  цвет/знак дельты переключается по знаку числа; шторка открывается по
  тапу и лениво грузит историю (не на маунте главной).
