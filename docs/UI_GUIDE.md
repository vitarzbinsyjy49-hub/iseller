# UI Guide — TechShop Mini App v2

Стиль: **Telegram Mini Apps × Яндекс Go / Яндекс Лавка** — светлый, чистый, mobile-first, плавный.

## Палитра

| Токен | Значение | Использование |
|---|---|---|
| `--app-bg` | `#F6F7F9` | фон приложения |
| `--app-surface` | `#FFFFFF` | карточки, поиск, панели |
| `--app-muted-bg` | `#F1F3F5` | вторичные кнопки, поля ввода |
| `--app-border` | `#E8EAEE` | разделители |
| `--app-text` | `#111827` | основной текст |
| `--app-sub` | `#6B7280` | вторичный текст |
| `--app-accent` | `#2AABEE` | Telegram blue: CTA, активные вкладки |
| `--app-accent-dark` | `#229ED9` | hover/тёмный акцент |
| `--app-green` | `#35C759` | «В наличии», «Сегодня», success |
| `--app-orange` | `#FF9F0A` | «Хит», акции |
| `--app-red` | `#FF3B30` | скидки, ошибки |

Токены объявлены в `frontend/src/index.css`, прокинуты в Tailwind через `tailwind.config.js`
(`bg-surface`, `text-muted`, `bg-accent`, `bg-green`, `bg-mutedbg`, …).

## Форма

- Радиусы: карточки/кнопки — `rounded-xl2` (20px), чипсы — `rounded-full`.
- Тени: `shadow-soft` — мягкая, двухслойная; у bottom sheet — `shadow-sheet`.
- Карточки товара: без рамок, белые, картинка `aspect-square` (не прыгает при загрузке).

## Motion system (чистый CSS, без зависимостей)

Все классы — в `frontend/src/index.css`. Тайминги 180–280ms, easing `cubic-bezier(.2,.8,.3,1)`.

| Класс | Эффект | Где используется |
|---|---|---|
| `page-enter` | fadeUp 220ms | смена страниц (key=pathname в `Layout.tsx`) |
| `card-appear` | fadeUp 240ms | появление карточек |
| `stagger` | каскад задержек 30ms на детей | сетки и ленты карточек |
| `sheet-in` | slideUp 260ms | bottom sheet заявки |
| `backdrop-in` | fadeIn 200ms + `backdrop-blur` | подложка bottom sheet |
| `pop-in` | scale 0.96→1 | success-состояние заявки |
| `tap` | scale 0.98 при нажатии | все кнопки и карточки |
| `skeleton` | shimmer 1.4s | загрузка данных |
| `typing-dot` | «AI печатает…» | чат AI-подбора |

`prefers-reduced-motion` отключает всё автоматически.

## Компоненты

- **ProductCard** (`components/ProductCard.tsx`) — картинка, бейджи (Хит / −N% / Сегодня),
  бренд, название (2 строки, фикс. высота), цена + old_price, наличие, кнопка «Заявка».
  Экспортирует `ProductImage` (градиентная заглушка при ошибке картинки) и `Badge`.
- **LeadForm** (`components/LeadForm.tsx`) — bottom sheet: имя, телефон (обязателен),
  комментарий, способ получения (Самовывоз Горбушка / Доставка по Москве), success state.
- **BottomNav** — 5 вкладок (Главная, Каталог, AI, Заявки, Профиль), SVG-иконки, blur-подложка.

## Экраны

1. **Home** — header (лого, «Горбушка · Москва», аватар), крупный поиск + кнопка «AI подбор»,
   плитки категорий 4×2, горизонтальные промо-блоки, секции «Хиты продаж», «Забрать сегодня», «Рекомендуем».
2. **Catalog** — поиск, чипсы категорий, сортировка, фильтры «В наличии»/«Забрать сегодня»/бренд/цена, сетка 2 колонки.
3. **AI** — чат: быстрые кнопки, bubble пользователя (синий), bubble ассистента (белый), typing-индикатор, карточки 2×N.
4. **Product Details** — крупное фото, бейджи, цена + «выгода», плитки условий (наличие/гарантия/самовывоз/доставка),
   описание, характеристики, **закреплённая CTA-зона** (Заявка / Забронировать / Спросить AI / Менеджер).
5. **Requests** — фильтры (Все/Новые/В работе/Завершённые), карточки со статусом, ценой, способом получения, комментарием менеджера.
6. **Profile** — аватар, бонусы-заглушка, меню (заявки, история, точка выдачи, помощь, о магазине).

## Правила

- Не добавлять тяжёлых анимационных библиотек без необходимости — CSS-система покрывает всё.
- Картинки всегда в фикс. контейнере `aspect-square` + `ProductImage` fallback.
- Реальные ассеты класть в `frontend/public/assets/{categories,banners,placeholders}/`.
- Никакого `dangerouslySetInnerHTML`.
