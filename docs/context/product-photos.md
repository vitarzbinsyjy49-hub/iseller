# Откуда брать фото товаров

> Читать, когда у карточек нет изображений: новый поставщик, новая категория,
> новые цвета. Здесь — рабочие адреса и тупики, чтобы не искать их заново:
> на первый прогон (07–08.09.2026) ушло несколько часов.

## Первое правило: фото должны лежать у нас

Внешняя ссылка в `Product.image` работает ровно до тех пор, пока жив чужой
сайт. **Так уже сгорел `rocketniks.ru`** — наш прежний источник картинок,
зашитый в `import_bsa.py`. Он лёг (DNS резолвится, но ни 80-й порт, ни ping не
отвечают ни с прода, ни из России), и вместе с ним осиротело всё, что он
раздавал. У ритейлеров адреса вдобавок меняются при пересборке карточки.

Поэтому после любого импорта с внешними URL:

```bash
ssh iseller "docker compose -f /opt/techshop/docker-compose.prod.yml exec -T backend \
    python -m app.scripts.internalize_photos --confirm"
```

Скрипт качает всё внешнее в `UPLOAD_DIR` через тот же `save_image`, что и
загрузка из админки, и переписывает `image`/`images` на `/api/uploads/...`.
Без `--confirm` — сухой прогон. Корневые пути (`/assets/...` из бандла
фронтенда) он считает своими и не трогает: иначе затёр бы карточку промо-
комплекта и плейсхолдеры.

## Apple: Scene7, три разных соглашения

База: `https://store.storeimages.cdn-apple.com/1/as-images.apple.com/is/<ассет>`
плюс `?wid=1200&hei=1200&fmt=jpeg&qlt=90`.

**На несуществующий ассет Scene7 отвечает не 404, а `403 text/plain` с текстом
«Unable to find image».** Проверять надо `content-type`, а не код ответа.

| что | ассет |
|---|---|
| Аксессуары | **номер детали как есть**: `is/MXMC3`, `is/MHJA3`, `is/MK2A3`, `is/MX5N3` |
| iPad Air | `ipad-air-finish-select-202405-<11inch\|13inch>-<blue\|purple\|space-gray\|starlight>` |
| iPhone 17 | `iphone-17-finish-select-202509-<black\|lavender\|white\|sage\|mistblue>` |
| iPhone 17 Pro/Max | `iphone-17-pro-finish-select-202509-<6-3inch\|6-9inch>-<silver\|deepblue\|cosmicorange>` |
| iPhone 17e | `iphone-17e-finish-select-<black\|white\|softpink>-202603` — дата **после** цвета |
| Mac mini | `mac-mini-chip-unselect-202608-gallery-1` (корпус M4 и M4 Pro одинаковый) |

**Apple Watch — кадр склеивается из слоёв**, разделитель `+` (кодировать его
нельзя):

```
<ремешок>ref_VW_34FR+watch-case-<размер>-titanium-<цвет>-cell-s11_VW_34FR+watch-face-<размер>-titanium-<цвет>-s11_VW_34FR_GEO_US
```

Набор слоёв угадать нельзя — он лежит в `og:image` страницы комплектации:
`apple.com/shop/buy-watch/apple-watch/46mm-cellular-slate-titanium-slate-milanese-loop`
(Ultra 3 — отдельная ветка `/apple-watch-ultra/`). Схема URL страницы
предсказуемая, так что нужную комплектацию можно открыть напрямую.

**Кадрирование.** Часть ассетов Apple отдаёт в 16:9 (iPad Air, iPhone 17 и
17 Pro, Mac mini): товар там мелкий, а запрос квадрата дорисовывает сверху и
снизу белые полосы — на карточке это читается как рамка вокруг серого
прямоугольника. Лечится `cropN=<x>,0,<доля>,1` — вырезает центральный квадрат
ДО масштабирования (`cropN` именно с заглавной N; строчная `cropn`
игнорируется). Для 16:9 это `cropN=0.21875,0,0.5625,1`.

Чего в Scene7 **нет**: HomePod 1-го поколения (Apple его не продаёт, перебраны
все правдоподобные имена 2017–2021) и Mac mini по номеру детали (`MU9D3`,
`MCX44` — 404, работает только галерейный ассет).

## Тупики, куда не возвращаться

- **Dyson закрыт полностью.** 403 на `dyson.com`, `.co.uk`, `.de`, `.fr`,
  `.co.kr`, `.com.sg`, `.in`, `.com.au`, `.co.jp`; WebFetch тоже 403; в живом
  браузере — капча Cloudflare. Их `dyson.scene7.com` отвечает, но имена
  ассетов есть только в HTML заблокированных страниц.
- Маркетинговые страницы Apple (`apple.com/ipad-air/`) отдают лайфстайл-кадры,
  для карточки они не годятся.
- `ipad-air-finish-<цвет>-2024` — кружок-образец цвета, а не товар.
- Конфигураторы Apple (Watch, iPad) подгружают галерею скриптом, из HTML
  картинку не достать — только через `og:image`.
- `s77.ru` не резолвится.

## Ритейлеры — когда производитель закрыт

Оба отдают чистый кадр в `og:image`:

| источник | чем полезен |
|---|---|
| `biggeek.ru` | каталог `/catalog/dyson?page=N` (по 27 позиций, ~112 всего) |
| `electricshop.com` | то, чего нет у BigGeek (так нашёлся Dyson TP14) |
| `kaercher.com` | свой CDN; URL страницы = номер материала без точек (`1.676-356.0` → `16763560`), картинка в `og:image` |
| `jura.com` | packshot'ы на `api.jura.com` |
| `restore.ru` | TP14 нет, только TP10 — но искать в нём можно |

**Сверять надо по названию карточки, а не по слагу.** У BigGeek слаг врёт: у
TP12 в адресе `NickelGold`, а в заголовке White/Gold; у Airwrap Ceramic Pink в
адресе `2025-2`, а в заголовке 2026. По слагам подобрался бы не тот цвет и не
тот год.

## Проверять отдачу, а не код ответа

Картинка засчитывается, только если это настоящий JPEG/PNG/WEBP не меньше
400×400 и не меньше 5 КБ — Scene7 и часть CDN отдают заглушки с кодом 200 или
403 и `text/plain`. Сеть при этом флапает: одиночный сбой ≠ битая ссылка,
нужен повтор (первые два прогона дали 32/33, причём падали разные позиции).
Полезно собрать контактный лист из всех картинок и посмотреть глазами — так
ловятся подмены цвета и поколения, которые по коду ответа неотличимы.
