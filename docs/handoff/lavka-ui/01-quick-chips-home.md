# ТЗ 01 — Личные чипы на главной

**Оценка:** S (полдня) · **Файлы:** `frontend/src/pages/Home.tsx`,
новый `frontend/src/lib/personalChips.ts` + тест · **Референс:** `frames/01-home.jpg`

---

## 1. Что у Лавки

Под лентой баннеров, до первой товарной секции, стоит ряд из четырёх чипов:

```
↺ уже брали     ♥ любимое     %скидки     ✨ новинки
```

Каждый — иконка + слово, без подложки-карточки, в одну строку с горизонтальной
прокруткой. Это единственное место, где личная история покупателя вытащена на
главный экран: всё остальное (история заказов, любимое) лежит в профиле, но
самые ходовые два входа продублированы наверх.

Приём работает, потому что первый экран отвечает не только новичку («вот
каталог»), но и возвращающемуся («вот то, что ты уже смотрел»).

## 2. Что у нас сейчас

- `/favorites` и `/history` существуют и работают (`App.tsx:125-126`), но вход в
  них **только из профиля** — три тапа от главной.
- Скидки живут как виртуальная категория `__sale__` в каталоге.
- На главной есть блок `QuickScenarios` (Trade-In / Продать) — это НЕ то же
  самое: там сценарии продажи, а не личная история покупателя.
- Есть секция «Вы недавно смотрели», но она рисуется **ниже баннеров** и только
  при ≥2 карточках — то есть как контент, а не как вход в раздел.

## 3. Что делаем

Ряд из **до четырёх** чипов между `QuickScenarios` и лентой баннеров
(`Home.tsx`, примерно строка 573 — сразу после `<QuickScenarios/>`, до
`lg:grid`-обёртки desktop-сетки). На desktop ряд скрыт (`lg:hidden`): там те же
входы уже есть в `HomeSidebar`.

| чип | иконка | маршрут | условие показа |
|---|---|---|---|
| Избранное | `heart` | `/favorites` | в избранном ≥1 товар |
| Вы смотрели | `history`/стрелка-по-кругу | `/history` | история просмотров ≥2 карточек |
| Скидки | `percent` | `/catalog?category=__sale__` | `sale_count > 0` (уже приходит в `/home` через `has_products`) |
| Новинки | `sparkles` | `/catalog?collection=hot` | всегда |

**Ни одного чипа с пустым содержимым.** Это то же правило, по которому плитка
без товаров не выходит на главную: чип, ведущий в пустой экран, хуже
отсутствующего чипа.

Если в итоге показывать нечего (новый пользователь без истории и избранного, в
каталоге нет скидок) — **ряд не рисуется вовсе**, `QuickScenarios` смыкается с
баннерами, вертикальный ритм не ломается.

## 4. Данные

Ничего нового на backend не нужно.

| что | откуда | примечание |
|---|---|---|
| избранное | `GET /api/favorites/ids` | самый дешёвый из двух эндпоинтов, отдаёт только id |
| история просмотров | `GET /api/catalog/recently-viewed?limit=20` | Home уже её запрашивает для секции «Вы недавно смотрели» — **переиспользовать существующий стейт, второй запрос не делать** |
| наличие скидок | `GET /api/home` | плитка `__sale__` уже отфильтрована по `has_products()`; если она пришла — скидки есть |
| новинки | — | `collection=hot` в `/catalog/list` |

`favorites/ids` на главной ещё не запрашивается — добавить один вызов в тот же
`useEffect`, где грузятся `/home` и `/catalog/categories`. Ошибка запроса =
чипа нет (не показываем скелетон и не блокируем ряд).

## 5. Вёрстка

- Горизонтальная лента `no-scrollbar -mx-4 flex gap-2 overflow-x-auto px-4`,
  как ряд чипов навигации выше.
- Сам чип: `h-11` (тач-таргет), `rounded-field`, `border border-border`,
  `bg-surface/70` — **тот же материал, что у чипов категорий в шапке**. Заводить
  для них отдельный вид нельзя: два разных оформления у двух рядов чипов на
  одном экране читаются как «эти кнопки чем-то принципиально отличаются».
- Иконка 16px слева, подпись `text-footnote font-medium`.
- Иконки берём из `components/icons.tsx` (`Icon name=...`); новых рисовать не
  нужно, кроме «истории» — если её там нет, добавить в общий набор, а не inline
  в `Home.tsx`.

## 6. Логика — в `lib/personalChips.ts`

Чистая функция, без React и fetch:

```ts
export type PersonalChip = { key: string; label: string; icon: string; route: string };

export function personalChips(input: {
  favoritesCount: number;
  recentlyViewedCount: number;
  hasSale: boolean;
}): PersonalChip[]
```

Тест `personalChips.test.ts` покрывает:
- пустой вход → `[]` (ряд не рисуется);
- только избранное → один чип;
- порядок чипов стабилен (избранное → смотрели → скидки → новинки);
- «Новинки» присутствуют всегда, кроме случая, когда список иначе был бы пуст;
- маршруты совпадают со строками из таблицы §3 (защита от опечатки в query).

## 7. Аналитика

```ts
track("personal_chip_clicked", { chip: "favorites" | "history" | "sale" | "new" });
```

Плюс однократно при первом показе ряда:
```ts
track("personal_chips_shown", { count: chips.length });
```
Это нужно, чтобы через неделю ответить на вопрос «а ими вообще пользуются» и не
спорить на вкус.

## 8. Крайние случаи

- **Товар удалили из избранного на другом экране** — при возврате на главную
  Home перезапрашивает данные; чип может исчезнуть. Это правильно, но переход
  не должен «прыгать»: ряд занимает высоту только когда чипы есть.
- **Оффлайн / ошибка `/home`** — работаем от того, что успело прийти; ряд
  строится из доступных признаков.
- **Кэш категорий** (`lib/categoryCache.ts`) на признак скидок не влияет —
  брать только свежий ответ `/home`.
