# ТЗ 07 — Кнопка «наверх» в длинных списках

**Оценка:** S (полдня) · **Файлы:** новый `frontend/src/components/ScrollTopButton.tsx`,
новый `frontend/src/lib/scrollTop.ts` + тест, подключение в `Catalog.tsx` ·
**Референс:** `frames/05-feed.jpg`, `frames/07-cards.jpg` (кружок со стрелкой слева внизу)

## 1. Что у Лавки

В глубине длинной выдачи слева внизу появляется полупрозрачный белый кружок со
стрелкой вверх. Он **не в углу экрана намертво**, а над доком, слева — там, где
не мешает ни карточкам, ни правой руке, тянущейся к «+» на карточке.

Появляется не сразу, а после нескольких экранов прокрутки, и исчезает наверху.

## 2. Что у нас сейчас

Ничего. В `Catalog.tsx` выдача до 50 карточек (`LIST_LIMIT`), это ~25 экранов
на телефоне. Единственный способ вернуться к фильтрам и сортировке — свайпать
вверх столько же, сколько листал вниз.

Хуже: сортировка и фильтры стоят **вверху** экрана, то есть именно туда человек
и хочет вернуться, посмотрев выдачу.

## 3. Что делаем

Плавающая круглая кнопка, общая для длинных списков. Первый и обязательный
потребитель — `/catalog`. Дальше по желанию: `/favorites`, `/history`,
`/requests` (там списки короче, и это не обязательная часть ТЗ).

### 3.1 Поведение

| условие | состояние |
|---|---|
| прокрутка < 2 высот экрана | кнопки нет |
| прокрутка ≥ 2 высот экрана | кнопка появляется (fade) |
| нажатие | скролл к началу списка, кнопка исчезает |
| открыта шторка фильтров/сортировки | кнопки нет |
| открыта клавиатура (`html.kb-open`) | кнопки нет |

Порог «2 высоты экрана» — а не фиксированные пиксели: на планшете и на iPhone SE
это разное количество карточек, а ощущение «я уже далеко» одинаковое.

### 3.2 Размещение

- `fixed`, слева, **над доком корзины** — то есть смещение снизу считается от
  той же `--bottom-nav-height`, что и `cart-dock`. Складывать `env()` во второй
  раз нельзя (двойной отступ на iPhone).
- Слева, а не справа: справа у карточек живёт степпер количества и сердечко
  избранного, и кнопка перекрывала бы их край.
- `z-20` — **ниже** дока корзины (`z-30`) и навигации (`z-40`).
- 44×44, `rounded-full`, `bg-surface/90`, `backdrop-blur`, `shadow-float`,
  `ring-1 ring-border`. Иконка — стрелка вверх из `components/icons.tsx`.
- `aria-label="Наверх"`.

### 3.3 Движение

Скролл — через существующий `animateScrollTo()` из `lib/motion.ts`, а не
`window.scrollTo({ behavior: "smooth" })`: у нас уже есть свой контроль
длительности и учёт `prefersReducedMotion()`.

**При включённом «уменьшении движения» прокрутка мгновенная**, не «быстрая».
Это не мелочь: жалоба «всё резко» почти всегда оказывается системной
настройкой телефона, и наш код обязан её уважать, а не бороться с ней.

Появление и исчезновение кнопки — `fade`, длительность из
`transitionDuration()`.

## 4. Логика — в `lib/scrollTop.ts`

```ts
/** Показывать ли кнопку «наверх» при данной прокрутке. */
export function shouldShowScrollTop(input: {
  scrollY: number;
  viewportHeight: number;
  screensThreshold?: number; // по умолчанию 2
}): boolean
```

Тесты:
- 0 → false; ровно 2 высоты → true (граница включительно);
- маленький вьюпорт (SE) и большой (планшет) дают одинаковое поведение в
  «экранах», а не в пикселях;
- `viewportHeight === 0` (нереалистично, но возможно при первом рендере) →
  false, а не деление на ноль.

Обработчик скролла — `passive: true` + `requestAnimationFrame`-throttle. Список
из 50 карточек с непассивным слушателем на скролле заметно дёргается в
Telegram-WebView.

## 5. Аналитика

```ts
track("scroll_top_clicked", { screen: "catalog", screens_scrolled: number });
```

`screens_scrolled` — округлённое `scrollY / viewportHeight`. Это ответ на
вопрос «а не слишком ли длинная у нас выдача», а не просто счётчик нажатий.

## 6. Крайние случаи

- **Смена категории** — выдача заменяется, скролл сбрасывается в 0, кнопка
  должна исчезнуть. Проверить: не «зависает» ли она после смены фильтра.
- **Возврат с карточки товара** — браузер восстанавливает позицию прокрутки;
  кнопка должна появиться сразу, без ожидания первого события скролла (считать
  видимость и на маунте тоже).
- **Desktop** — кнопка не нужна: там колесо и `Home`. Скрыть через `lg:hidden`.
- **Шторка фильтров** блокирует скролл body — кнопка под ней не должна
  просвечивать.

## 7. Готово, когда

- [ ] В каталоге кнопка появляется после ~2 экранов и возвращает к началу.
- [ ] При `prefers-reduced-motion: reduce` прокрутка мгновенная.
- [ ] Кнопка не перекрывает док корзины, степпер на карточках и не всплывает
      над шторкой фильтров.
- [ ] Слушатель скролла пассивный, прокрутка 50 карточек не дёргается на
      реальном телефоне в Telegram.
- [ ] `scrollTop.test.ts` зелёный.
- [ ] На desktop кнопки нет.
